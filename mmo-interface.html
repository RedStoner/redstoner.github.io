MMO Plugin

UI & Commands

Every in-game screen the plugin opens, and the full player and admin command reference.

UI Screens

Screen Opened by Purpose
Dashboard /qlmmo ui (aliases: dashboard, gui) Root hub with tabs for Party, Guild, and LFG.
Guild Shortcuts /guild Quick-action menu — Home, Roster, Permissions, Hall Upgrade, Chest. Buttons hide based on the player’s permissions.
Guild Panel /guild ui Tabbed roster, info (MOTD, founded date, member count), and treasury views.
Guild Permissions From the guild panel or the shortcuts menu Owner-only matrix editor for rank permissions and per-player overrides.
Guild Chest /guild chest Tabbed multi-section inventory with deposit and withdraw controls (gated by chest permissions).
Hall Creation Carousel Auto-opens for the owner on first /guild home Two-step picker: biome then template, with preview images and confirmation.
Hall Upgrade Guild Shortcuts > Hall Upgrade Mode-aware: PREFAB shows next-tier preview and cost; BUILD shows next-level features and cost.
LFG Browser /lfg Searchable, clickable listing rows with role filter, role-aware join, an in-UI Create Listing form, and a request-management panel (with Cancel Listing) for the listing author.
Discoveries /discoveries / /poi Player’s POI log with progress count and per-POI details.
Dungeon HUD Auto-opens on instance entry Persistent overlay: boss health, timed objective countdown, member status (ALIVE/DEAD/DISCONNECTED).
Checkpoint Respawn Auto-opens on death in a dungeon Modal screen showing last checkpoint, respawn countdown, Respawn / Leave buttons.
Event Tracker HUD Auto-opens for players in an active event region Read-only HUD showing the current event objective and time remaining; world boss countdowns.

Admin Commands

All admin commands live under /qlmmo. The base permission questlinesmmo.admin gates the /qlmmo admin hierarchy.

Plugin

CommandPermissionDescription
/qlmmo helpquestlinesmmo.qlmmo.helpList subcommands.
/qlmmo infoquestlinesmmo.qlmmo.infoPlugin status and counts.
/qlmmo ui (aliases dashboard, gui)questlinesmmo.qlmmo.uiOpen the plugin dashboard.
/qlmmo reloadquestlinesmmo.qlmmo.reloadReload config.json and every registry folder; pushes the new values into all running managers.

POI Authoring

POI authoring writes JSON files to mods/QuestLinesMMO/pois/ directly. Each command requires its corresponding permission node; players use /discoveries for the read-only player-facing UI.

CommandPermissionDescription
/qlmmo poi here <id> [radius=16] [displayName...]questlinesmmo.qlmmo.poi.hereCreate a POI at your current position; writes pois/<id>.json.
/qlmmo poi remove <id>questlinesmmo.qlmmo.poi.removeDelete a POI by id.
/qlmmo poi listquestlinesmmo.qlmmo.poi.listList every registered POI with id, world, centre, and radius.
/qlmmo poi info <id>questlinesmmo.qlmmo.poi.infoShow full details of a single POI.
/qlmmo poi tp <id>questlinesmmo.qlmmo.poi.tpTeleport to a POI’s centre.
/qlmmo poi grant <player> <id>questlinesmmo.qlmmo.poi.grantMark a POI as discovered for a player without their visiting it.
/qlmmo poi revoke <player> <id>questlinesmmo.qlmmo.poi.revokeRemove a single POI discovery from a player.
/qlmmo poi reset <player>questlinesmmo.qlmmo.poi.resetWipe every POI discovery for a player.
