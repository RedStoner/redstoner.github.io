Migration & API

Migrating from HyCitizens, the optional NameplateBuilder and Titles integrations, and the developer API for driving Denizens from other plugins.

HyCitizens Import

/denizen import-hc [dry] performs a one-way migration from HyCitizens. It is a clean-room reader — it parses HyCitizens’ on-disk data file (mods/HyCitizensData/data.json) and never touches HyCitizens code — so it works whether or not HyCitizens is installed.

Equipment recovery

For armor / equipment to be recovered, the source citizens need to be loaded. Run a dry run first to confirm the counts look right before the real import.

NameplateBuilder

When Frotty27:NameplateBuilder is installed, Denizens registers built-in nameplate segments and the editor exposes a Nameplate tab for editing per-Denizen segment text. This gives multi-line, reorderable, restylable nameplates that coexist with segments from other plugins.

Built-in segmentDefault text
denizen.titleQuest Giver
denizen.subtitleLvl 5

Segment values are stored on the Denizen’s Appearance.Nameplate.Segments map and pushed to the entity at spawn. All bytecode references are isolated in a bridge class, so the plugin loads cleanly when NameplateBuilder is absent (the segment editor is simply hidden).

Titles

With net.evilcraft:QuestLinesTitles installed, set Appearance.Nameplate.TitlesIntegration to true to surface a title in the Denizen’s nameplate. See the Titles documentation for how titles are defined and formatted.

Developer API

Denizens exposes a cross-classloader-safe API object for other plugins. It is resolved by reflection so callers need no compile-time dependency on Denizens: 

PluginBase denizens = HytaleServer.get().getPluginManager().getPlugin(
        new PluginIdentifier("net.evilcraft", "QuestLinesDenizens"));
Object api = denizens.getClass().getMethod("getApi").invoke(denizens);
// then invoke DenizensAPI methods reflectively

The API surface groups into:

LookupsfindByNameOrId, findByShortId, getShortId, exists, isSpawned, getEntityUuid, listAllIds, listIdsInWorld, getSnapshot

Lookups return lightweight Snapshot / QuestAssignment records so callers never need the Denizens classes themselves.
