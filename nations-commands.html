Nations Plugin

Commands

Full reference for the four command trees: /city, /nation, /citiesadmin, /nationsadmin. Permissions and member-only gates are noted in the “needs” column.

/city

Bare /city opens the City Overview UI for your current city, or prints a hint if you’re not in one. All other /city activity is dispatched through the subcommands below.

Lifecycle

CommandNeedsWhat it does
/city create <player> <name> <tag> [#color] [motd...]Not in a cityCharges create_city_cost (sunk); opens a PendingCityCreation waiting for the named player.
/city create cancelPending creation as founderAborts the pending row. Cost stays gone.
/city accept <name>—Accepts a pending creation (you’re the invitee) or an ordinary invite.
/city decline <name>—Rejects a pending creation or invite to that named city.
/city disbandMayorDouble-confirmed teardown. Releases all claims, refunds treasury per config.

Ranks, settings, diplomacy, bank, tax

Same shapes as the city tier, scoped to the nation. Key differences:

  • /nation setrank targets a city, not a player; cannot target the capital.
  • /nation tax pay is run by any member-city mayor and drains that city’s treasury to clear the city’s arrears.
  • /nation tax capitalexempt true|false replaces founderexempt.
  • There is no /nation setcd standalone command in v3.0.0 — capital-district relocation is done by the capital-transfer flow.

Admin Commands

The two admin trees require questlinesnations.admin. Conquest commands at both tiers use a two-step confirm-token pattern: the first invocation prints a token, you re-run with the token appended within conquest_confirm_token_ttl_seconds (default 60) to execute.

/citiesadmin

CommandWhat it does
/citiesadmin reloadReload questlinesnations.conf.
/citiesadmin delete <cityName>Force-disband without grace.
/citiesadmin setmayor <cityName> <player>Override mayor without target consent.
/citiesadmin setperm <cityName> <player> <perm> on|offDirectly edit one member’s bitmask snapshot.
/citiesadmin unclaim <cityName> <x> <z> [world]Force-release one city chunk.
/citiesadmin unclaimall <cityName>Force-release every chunk the city owns.
/citiesadmin conquer <loser> <winner> [claims|absorb] [token]Confirm-token gated. claims moves chunks only; absorb additionally folds members into the winner.
/citiesadmin treasury set <city> <amount>Rewrite treasury balance; logs as admin.

/nationsadmin

CommandWhat it does
/nationsadmin reloadReload config.
/nationsadmin delete <nationName>Force-disband without grace.
/nationsadmin setcapital <nationName> <cityName>Override capital without consent.
/nationsadmin setperm <nationName> <cityName> <perm> on|offDirectly edit a member-city’s perm snapshot.
/nationsadmin unclaim <nationName> <x> <z> [world]Force-release one nation chunk.
/nationsadmin unclaimall <nationName>Force-release every nation chunk.
/nationsadmin war end <nationA> <nationB> [note]Admin-terminate an active war.
/nationsadmin war setstatus <nationA> <nationB> <status>Override WarStatus.
/nationsadmin conquer <loser> <winner> [claims|absorb] [token]Confirm-token gated nation conquest.
/nationsadmin treasury set <nation> <amount>Rewrite nation treasury; logs as admin.

See Conquest for the claims-vs-absorb semantics.
