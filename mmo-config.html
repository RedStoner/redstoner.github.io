MMO Plugin

Configuration

Plugin tunables in config.json, the folder-backed registry files that define content, the on-disk layout, and what /qlmmo reload does.

Configuration

Plugin tunables live in mods/QuestLinesMMO/config.json. Subsections cover party, guild, guild hall, dungeon, LFG, events, world bosses, and POIs. Almost every section is hot-reloadable via /qlmmo reload — the reload also rescans every registry folder.

Registry Files

Most content lives in folder-backed registries. Every folder is scanned for *.json files at startup and on /qlmmo reload; the filename (minus .json) becomes the entity id and must match the id field inside the JSON. Unknown fields are ignored. Defaults from src/main/resources/defaults/ are copied to disk on first run and never overwritten afterwards.

Hot Reload

/qlmmo reload reloads config.json and every registry folder, then pushes the refreshed values into all running managers (applyConfig(...)). The following are not affected by a reload — they keep running with their captured settings until they end:

  • Active dungeon instances.
  • Active dynamic events.
  • In-flight party, guild, and LFG invites.
  • Currently loaded guild hall worlds (their hall metadata reloads, but in-progress upgrades complete with their original cost).
  • Player data — friend lists, progression, guild membership are unaffected.

The reload command logs per-entry results to console; if a registry file fails to parse, the broken file is skipped and the previous in-memory definition (if any) is retained.
