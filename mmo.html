QuestLines MMO

A standalone MMO feature suite for Hytale. Parties and friends, guilds with ranks and a shared treasury, instanced guild halls, dungeon instances with checkpoints and boss phases, an LFG browser, dynamic region events, world boss schedules, and player-discoverable POIs — all served from a single plugin.

How It Works

QuestLines MMO is a self-contained plugin: it does not require QuestLines Core and shares no APIs with the rest of the suite. Players use chat commands and in-game UIs to form parties, run guilds, queue for content, and explore the world; admins author dungeons, events, guild hall templates, and POIs as JSON files in the plugin’s data directory.

Most subsystems are built on the same pattern: an immutable definition loaded from a folder under mods/QuestLinesMMO/, a registry that hot-reloads from disk, a manager that holds runtime state, and a set of listeners that drive the loop. Adding a new dungeon, event, or POI is a matter of dropping a JSON file in the right folder and running /qlmmo reload.

ℹ
Standalone plugin

QuestLines MMO ships as questlines-mmo-{version}.jar with its data directory at mods/QuestLinesMMO/. It runs without any other QuestLines plugin installed. QuestLines Claims is an optional integration that, when present, lets guild halls delegate chunk protection and rent/sale plots to Claims.

Feature Pillars

Pillar Player command Summary
Parties /party Short-lived groups for running content together. Leader-driven invites, kicks, transfers. Details
Friends /friend Persistent bidirectional friend list with online status. Details
Guilds /guild Long-lived player organisations with four ranks, permission overrides, MOTD, currency, and a tabbed shared chest. Details
Guild Halls /guild home Per-guild instanced world. PREFAB mode pastes upgrade tiers; BUILD mode lets members build inside claimed chunks. Details
Dungeons /dungeon enter Instanced PvE content with checkpoints, boss phases, timed objectives, and disconnect grace. Details
LFG Browser /lfg Post and join group listings filtered by content and role (TANK / DPS / HEALER / ANY). Details
Dynamic Events (world-driven) Region-triggered events that fire when player count is high enough; success rewards distributed by participation. Details
Event & World Bosses (world-driven) Cron-scheduled world bosses with configurable announcements; event bosses spawn during dynamic events. Details
Discoveries (POIs) /discoveries Proximity-detected points of interest. Discovering one fires a notification, optional rewards, and adds the POI to the player’s map. Details
