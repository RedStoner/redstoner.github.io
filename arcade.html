Arcade Plugin

QuestLines Arcade

A standalone multiplayer arcade engine for Hytale. A shared lobby, matchmaking, match lifecycle, two-currency wallet, and on-disk persistence — with thin per-game modules on top. Ships as a core plugin (engine + 10 sample games) plus five independent DLC packs that each add their own games, configs, and themed cabinets/tables.

Elevator Pitch

Drop the JARs in mods/ and every player gets a /arcade command that opens a lobby of every registered game. Place an arcade cabinet, slot machine, or poker table in your world and right-clicking it opens the same lobby pre-targeted to a category or a specific game. Players queue up, the engine matches them, the per-game module renders its own UI inside a chrome frame that handles the roster, log, and chat for free. When a match ends, w/l/d, Elo, and a JSON archive of the result are written to disk.

Arcade is fully independent of QuestLines Core. It has its own multi-project Gradle build, its own data directory, and its own version line. The only outside hook is the optional VaultUnlocked bridge that lets the wallet exchange tokens and chips against the server economy.

The Engine and the Packs

Arcade is a multi-project Gradle root. The core JAR ships the engine and a sample roster of 10 games; each DLC pack is its own JAR that registers additional games and per-game configs into the core engine on startup.

JAR Plugin Name Games Adds
questlines-arcade-{version}.jar QuestLinesArcade 10 Engine, lobby, wallet, persistence, commands, and the base game roster (Tic-Tac-Toe, Four Up, Salvo, Chess, Go, Dominoes, Minesweeper, 2048, Code Breaker, Worm).
questlines-arcade-board-pack-{version}.jar QuestLinesArcadeBoardPack 5 Reversi, Checkers, Pachisi, Liar’s Dice, Backgammon. Themed tables (Board_Table_Checkers, etc.) for each game.
questlines-arcade-casino-pack-{version}.jar QuestLinesArcadeCasinoPack 7 Texas Hold’em, Casino Blackjack, Blackjack (solo), Video Poker, Roulette, Craps, Slot Machine. The only pack that charges chips.
questlines-arcade-solo-pack-{version}.jar QuestLinesArcadeSoloPack 7 Solitaire, FreeCell, Sudoku, Stacker, Yacht Dice, Crystal Drop Endless, Crystal Drop Moves. All free.
questlines-arcade-puzzle-pack-{version}.jar QuestLinesArcadePuzzlePack 5 Word Search, Crosswords, Lights Out, Nonograms, Kakuro. All free.
questlines-arcade-supersecret-pack-{version}.jar QuestLinesArcadeSuperSecretPack 4 Carcassonne, Catan (tokens), Cards Against Humanity, Uno (free).

Every DLC declares net.evilcraft:QuestLinesArcade as a manifest dependency and resolves the core API classes via Hytale’s plugin classloader at runtime. Each subproject is built and shipped independently; installing a pack is opt-in — you only get what you drop in mods/.

Two Wallet Currencies

Every game declares a GameMode that fixes which wallet the engine charges:

Mode Currency When charged
ARCADE Tokens One-off entry fee at match start (tokensPerArcadeGame, default 1). Refunded if the match cancels before the first move.
CASINO Chips Per-round / per-hand bets that the controller manages during the session. The match-start check only verifies the player has enough chips to cover one bet.
FREE — No wallet check, no fee. Most solo and puzzle games are free.

New players are auto-seeded with startingTokens the first time they run /arcade or right-click a cabinet, and can claim a small daily token grant via /arcade-wallet daily. Tokens and chips can be exchanged at the rates set in config.json; if VaultUnlocked is installed, both currencies can be bought from or sold to the server economy. See Wallet & Economy for the full set of subcommands and rates.

Match Lifecycle

Arcade keeps the engine and the games strictly separated. A GameDefinition describes a game (id, display name, layout path, capabilities, categories, mode); a GameController drives it. Every live match flows through the same six states:

State What it means
CREATEDMatch object built, controller’s onCreate fired.
LOBBYAccepting joins. Players can leave freely; their seat is reclaimed.
RUNNINGEntry fee charged, controller’s onStart fired. MatchStartListeners receive a MatchInfo snapshot. Leaving forfeits.
ENDEDWin or draw outcome.
FORFEITEDA player left a running match. The remaining connected player wins.
CANCELLEDMatch was aborted before completion — either the last player left during LOBBY, or entry charging failed. Cancelled matches do not affect Elo or w/l/d totals.

When a match reaches a terminal state, the engine writes a MatchArchive JSON under mods/QuestLinesArcade/archive/<yyyy-MM>/<matchId>.json and updates every participant’s profile. For two-player matches only, Elo is recomputed with K=32 and a 1200 starting rating. Three-or-more-player games still record wins, losses, draws, and last-played timestamps per game.

The match-creation cap is maxConcurrentMatches (default 64, engine-global). Past that, createMatch returns null and the caller’s API call resolves to JoinResult.Status.AT_CAPACITY.

How Players Get Into a Game

There are three ways into a match:

  1. The lobby command. Running /arcade opens the full lobby UI: pick a category, pick a game, then queue or invite. If the player is already in a live match, /arcade re-opens that match’s UI instead.
  2. Cabinets and tables. The block listener intercepts F/Use on any block whose Interactions.Use is Arcade_Open. Most cabinets open the lobby pre-targeted to a category (the Board Pack’s Arcade_Machine_Board jumps to the BOARD category; the cocktail variants jump to ARCADE); the casino pack’s named tables (Poker_Table_Holdem, Poker_Table_Blackjack, Roulette_Table) jump straight to that game’s detail page. See Cabinets & Tables for the full block list.
  3. External plugins via the API. Any plugin can call ArcadeAPI.openMatch(uuid, gameId) or queuePlayer(uuid, gameId) to launch a player straight into a game — useful for quest rewards, NPC interactions, or admin tools. See Developer API.

Once a game has at least minPlayers queued, a 30-second countdown begins. Hitting maxPlayers short-circuits the countdown and starts the match immediately; dropping back below minPlayers cancels it. The countdown does not extend when additional players join.

Where Data Lives

All persistence is plain JSON on disk, under the data directory mods/QuestLinesArcade/:

Path Contents
config.json Engine-wide settings — currency rates, starting tokens, daily grant, match cap, Vault settings.
configs/<gameId>.json Per-game tunables. One file per game that registers a config (Code Breaker, Minesweeper, 2048, every Casino game, Pachisi, Yacht Dice, Carcassonne, CAH).
profiles/<uuid>.json One file per player — wallet, display name, total w/l/d, per-game Elo and stats, daily-claim timestamp.
archive/<yyyy-MM>/<matchId>.json One file per completed match. Includes participants, outcome, winners, start/end timestamps, and any note from the result.

Writes go through a dedicated single-thread executor and use the standard atomic temp-file-then-rename pattern, so player profiles are never half-written even if the server is killed mid-match.

Player Commands at a Glance

All three commands are registered by the core JAR. There are no additional commands added by the DLC packs.

Command Audience Summary
/arcade Everyone Opens the lobby (or your current match’s UI if you’re already in one). Seeds your wallet on first use.
/arcade-wallet Everyone Balance, daily claim, token/chip exchange, and Vault buy/sell.
/arcade-debug Operators (questlinesarcade.admin) Match/queue/invite/leaderboard/wallet scaffolding. Includes a hot-seat mode that lets one player drive every role of a multiplayer game for testing.
