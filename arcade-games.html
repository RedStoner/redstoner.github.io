Arcade Plugin

Game Catalog

Every game shipped by Arcade, organized by pack. 38 games total — the core JAR registers 10, and each of the five DLC packs adds its own roster. Currency, category, and player-count columns reflect what each GameDefinition actually declares in code.

ℹ
Reading the table

Mode: ARCADE = tokens entry fee, CASINO = chips per round, FREE = no wallet check. Players: the (minPlayers, maxPlayers) capability declared by the game. Categories: every category the game appears in (a single game can show up in multiple lobby categories).

★
Slot machine payouts

Slot Machine multipliers are baked into the Symbol enum, not the per-game config: cherry 5×, silver 10×, gold 20×, ruby 50×, emerald 100×, diamond 500×. The config only controls the bet size and the any-two-cherries consolation payout.

ℹ
The Super Secret cabinet is unwired

The pack ships an Arcade_Machine_SuperSecret block with the standard Arcade_Open use interaction, but that block id is not in the listener’s CATEGORY_BY_BLOCK or GAME_ID_BY_BLOCK maps, and Category has no SUPERSECRET entry. Today the Super Secret games are reachable only through the overlapping STRATEGY, BOARD, CARD, and MULTIPLAYER category portals (or via /arcade). The block is harmless — right-clicking it just does nothing.

What Gets Recorded

After a match reaches a non-cancelled terminal state, the engine updates each participant’s profiles/<uuid>.json:

  • Top-level totals: totalMatches, wins, losses, draws.
  • Per-game stats keyed by game id: elo (2-player matches only, K=32, starting 1200), wins, losses, draws, lastPlayed.

A separate archive file under archive/<yyyy-MM>/<matchId>.json records the participants, outcome, winners, start/end timestamps, and any closing note from the result. Cancelled matches are not archived and do not affect any stats.

Per-game leaderboards are computed on demand by scanning every profiles/*.json for a stats entry for the requested game and sorting by Elo. The lobby caches the top 3 per game; admins can pull a longer list with /arcade-debug leaderboard <gameId>.
