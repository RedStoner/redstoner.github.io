Claims Plugin

Admin Regions

Admin-defined protected zones drawn with the Claim Staff — rectangular or polygonal, with numeric priority and per-flag exclusions.

Admins define protected regions with a wand workflow. Regions can be rectangular (two corner clicks) or polygonal (three or more vertex clicks).

Rectangular Regions

  1. Run /claim wand to receive the Claim Staff.
  2. Rectangle (default): left-click a block to set Pos1, right-click a block to set Pos2.
  3. A selection box outline renders between the two corners.
  4. Run /claim admin to open the admin region list, then Create from Wand Selection.

If a client-side mod conflicts with the Claim Staff click handler, the same selection can be built from commands instead: /claim pos1 and /claim pos2 set each corner to your current block, /claim select <x1> <y1> <z1> <x2> <y2> <z2> sets both corners at once from explicit coordinates, and /claim deselect clears the selection. They write to the same wand session and trigger the same selection box outline.

The creation form asks for name, priority, type (Admin / Rent / Buy), and — for rent/buy — price and duration. Checking Expand Y extends the region vertically to cover the full world height regardless of the clicked Y coordinates.

ℹ
Claim Staff

The Claim Staff is a Hytale item defined in Server/Item/Items/QuestLinesClaims_Staff.json. It is identified by an item NBT tag, so the underlying model can be swapped without code changes. The wand session is in-memory only and resets if the player disconnects.

Polygon Regions

For irregular shapes — carving around a building, following a coastline, or excluding a small interior — toggle polygon mode with /region polymode (also registered as /claim polymode). Each wand click then adds or removes a vertex instead of setting Pos1/Pos2:

  • Left-click a block to add a vertex at that XZ position.
  • Right-click a block to remove the most recently added vertex.
  • The selection visualiser highlights every vertex as a cyan cube and connects consecutive vertices with a solid edge.
  • A polygon needs at least three vertices before /region create will save it.

Wand-less alternatives mirror the wand while polygon mode is on: /region pos1 adds a vertex at your current block, and /region pos2 removes the last vertex. /region deselect clears every vertex (and Pos1/Pos2). Running /region polymode again exits polygon mode and clears any in-progress vertex list.

Containment uses a point-in-polygon test on the XZ plane. The vertical range is controlled by the Min Y / Max Y inputs in the region edit form (auto-seeded from the wand clicks' Y values; you almost always want to widen this to a sensible floor and ceiling). Checking Expand Y hides the Min Y / Max Y inputs and stretches the region to the full world height regardless. Polygon support carries through to every region type: admin, rent, buy, and guild-hall.

⚠
Schematics are AABB-only

Saving and restoring rent/buy schematics still uses the polygon's axis-aligned bounding box because Hytale's Prefab API only takes a rectangular volume. Blocks inside the AABB but outside the polygon will be captured and overwritten on restore. For now, keep schematic-using rent/buy regions rectangular and use polygons primarily for protection and visual claim boundaries.
