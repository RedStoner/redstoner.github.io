Arcade Plugin

Wallet & Economy

Arcade keeps two per-player currencies — tokens (most strategy games) and chips (every casino game) — and optionally lets players exchange them, claim a daily token grant, and (with VaultUnlocked installed) buy or sell either currency against the server economy.

Two Currencies

Currency Charged for Earned from
Tokens One-off entry fee at match start for every ARCADE-mode game (default 1 token per match). Starting grant on first /arcade use, the daily claim, exchange from chips, or buying with Vault money.
Chips Per-round / per-hand bets in every CASINO-mode game. The controller manages chip flow during the session; the engine just verifies the player can cover one bet at start. Casino game wins, exchange from tokens, or buying with Vault money.

Free games charge neither. Tokens and chips never decrease silently — setChips() and setTokens() floor at zero.

Player Flow

  1. First run of /arcade (or first cabinet click) seeds the wallet with startingTokens (default 10) and 0 chips. Profiles are created lazily — nothing is written until a player actually engages.
  2. /arcade-wallet daily grants dailyTokens (default 5). Cooldown is dailyCooldownHours (default 24) from the last successful claim, reported in seconds remaining if not yet ready.
  3. /arcade-wallet tokens-to-chips <tokens> swaps tokens for chips at chipsPerToken (default 10 chips per token).
  4. /arcade-wallet chips-to-tokens <tokens> swaps chips back. The argument is the number of tokens you want; the chip cost is tokens × chipsPerOneToken (default 15 chips per token — so there’s a built-in spread between buying and selling).
  5. Both exchange subcommands require exchangeEnabled = true (default). Set it to false to lock exchanges off entirely.
★
The chips-to-tokens argument

The argument is the number of tokens the player wants to receive, not the number of chips they want to spend. So /arcade-wallet chips-to-tokens 3 at the default rate deducts 45 chips and credits 3 tokens. This is opposite to how most exchanges read — worth highlighting in your server’s rules text.

VaultUnlocked Integration

VaultUnlocked is Arcade’s only optional dependency. When installed and registered, it unlocks four extra wallet subcommands that bridge between server money and Arcade currency:

Subcommand Direction Rate field Default
buy-tokens <count> Server money → tokensvaultCostPerToken 100.0 per token
sell-tokens <count> Tokens → server moneyvaultPayoutPerToken50.0 per token
buy-chips <count> Server money → chipsvaultCostPerChip 15.0 per chip
sell-chips <count> Chips → server moneyvaultPayoutPerChip7.0 per chip

Both vaultEnabled = true and a successfully-detected Vault provider are required — otherwise the four subcommands respond “Vault is not available” and do nothing. The default currency is whichever currency the Vault provider considers default; override with vaultCurrency in config.json if your provider supports multiple.

Sell paths are refund-safe: tokens or chips are deducted first, then deposited as money; if the deposit call fails, the deducted currency is returned to the player and an error is reported. Buy paths fail forward — money is withdrawn first, and only then is the Arcade currency credited.

ℹ
Vault detection is one-shot at startup

Arcade resolves Vault’s economy provider once at plugin start and caches the reflective method handles. Installing or replacing Vault while the server is running will not make the new provider visible — a server restart is required.

Tuning Rates

All wallet-related rates live in config.json under mods/QuestLinesArcade/. Tweaking is hot — reload changes by restarting the plugin or the server. See Engine Config for the full list of fields and their defaults.

  • To raise the casino floor: increase chipsPerToken (make chips harder to get via exchange) or raise vaultCostPerChip (make Vault-bought chips cost more).
  • To make the daily grant matter: raise dailyTokens relative to tokensPerArcadeGame. At default rates (5 tokens daily, 1 per match) a player gets 5 free strategy matches per day.
  • To turn off Vault entirely without uninstalling it: set vaultEnabled = false. The bridge stays loaded but the four subcommands respond “Vault is not available.”
  • To remove all exchange: set exchangeEnabled = false. tokens-to-chips and chips-to-tokens both refuse; buy-* and sell-* are unaffected.
