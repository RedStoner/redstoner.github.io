NpcQuestIcons

Floating quest-icon holograms above NPCs — command reference & configuration guide

Overview

NpcQuestIcons spawns floating 3-D item entities above NPCs to communicate quest status to players. Each NPC can show a different icon depending on the player's quest progress, and every visual property — icon item, height, scale, rotation, and animation — can be tuned per NPC via in-game commands without restarting the server.

The root command is /icons (alias: /i).

Wand mechanic Most subcommands work as a "wand": run the command to queue a pending assignment, then click any NPC to apply it. The pending assignment expires when you log out or run the command again with different values.

How it works

When integrated with QuestLines, each QuestLines NPC gets four icon entities spawned above it — one per quest state. Each tick, PerPlayerQuestIconSystem filters each player's visible-entity set so they only see the icon matching their current quest progress. This is purely a visibility filter; the entities always exist in the world.

For NPCs not in QuestLines, a single static icon entity is used instead, showing the same item to every player.

Commands

/icons icon

/icons icon [--itemid <itemId>] [--state <state>]
Queues an icon assignment. Click an NPC to apply it. If itemId is omitted, the item currently held in your active hotbar slot is used. An empty hand sets the icon to none (hidden).
ParameterTypeDescription
--itemid optional string Item ID to display, default to clear the per-NPC override (falls back to the global default), or none to disable the icon for this NPC. Omit to use the held item.
--state optional string Quest state to target: available, inprogress, completed, unknown. When provided, the icon is stored as a per-state entry (NpcQuestIconStates) rather than the NPC-level override (NpcQuestIcons). Omit to set the icon at the NPC level. 
# Use the item in your hand (NPC-level)
/icons icon

# Explicit item ID
/icons icon --itemid Icons_Exclamation

# Hide the icon for this NPC
/icons icon --itemid none

# Remove the per-NPC override (revert to global default)
/icons icon --itemid default

# Set the icon shown only when the player's quest is in progress
/icons icon --itemid Icons_Dots --state inprogress

# Set the "available" state icon using the held item
/icons icon --state available

Changes are saved immediately to mods/Icons/icons.json. Without a state argument, sets NpcQuestIcons (NPC-level override, shown to all players regardless of quest state). With a state argument, sets NpcQuestIconStates (per-player, per-state — only visible when the player's quest matches that state).

/icons offset

/icons offset --offset <offset>
Queues a Y-offset assignment. Click an NPC to apply it. The offset is added on top of the base height (NpcHologramManager.QUEST_ICON_Y_OFFSET).
ParameterTypeDescription
--offset required double Y-offset in blocks (positive = higher). Pass 0 to clear the override. 
# Raise the icon 0.5 blocks above the default height
/icons offset --offset 0.5

# Lower the icon
/icons offset --offset -0.3

# Clear the override
/icons offset --offset 0

/icons scale

/icons scale --scale <scale>
Queues a scale assignment. Click an NPC to apply it.
ParameterTypeDescription
--scale required float Scale multiplier. 1.0 = default size. Pass 1.0 to clear the override. 
# Double the icon size
/icons scale --scale 2.0

# Half size
/icons scale --scale 0.5

# Reset to default
/icons scale --scale 1.0

/icons rotation

/icons rotation --degrees <degrees>
Queues a Y-axis rotation assignment. Click an NPC to apply it. This sets a fixed starting rotation; combine with the rotate animation for continuous spin.
ParameterTypeDescription
--degrees required float Y rotation in degrees (0–360). Pass 0 to clear the override. 
# Rotate 45 degrees on spawn
/icons rotation --degrees 45

# Clear the override
/icons rotation --degrees 0

/icons animate

/icons animate --animation <animation> [--state <state>]
Queues an animation assignment. Click an NPC to apply it. Multiple animation types can be active on the same icon simultaneously — running the command again with a different type adds it rather than replacing the existing ones.
ParameterTypeDescription
--animation required string Animation specifier — see format below.
--state optional string Quest state to target: available, inprogress, completed, unknown. Omit to apply the animation at the NPC level (all states).

Animation format

<type>[:speed[:amplitude]]  — speed and amplitude are optional and have per-type defaults.

bob

Moves the icon up and down.
Speed: Hz  |  Amplitude: blocks
Defaults: speed=1.0, amplitude=0.2

rotate

Continuously spins on the Y axis.
Speed: degrees/sec
Default: speed=45

pulsate

Smoothly oscillates the scale.
Speed: Hz  |  Amplitude: scale delta
Defaults: speed=1.0, amplitude=0.2

sway

Rocks side-to-side on the Z axis.
Speed: Hz  |  Amplitude: degrees
Defaults: speed=1.0, amplitude=15

orbit

Circles horizontally around the NPC.
Speed: Hz  |  Amplitude: radius in blocks
Defaults: speed=0.5, amplitude=0.5

ping

Brief sharp scale pop (like a notification).
Speed: Hz  |  Amplitude: max scale delta
Defaults: speed=0.5, amplitude=0.4

Clearing animations

SyntaxEffect
noneRemove all animations from this NPC
none:<type>Remove only the specified animation type (e.g. none:rotate)
 
# Bob at default speed and amplitude
/icons animate --animation bob

# Spin at 90 degrees/sec
/icons animate --animation rotate:90

# Orbit at 0.5 Hz with 1.5 block radius
/icons animate --animation orbit:0.5:1.5

# Sway ±20 degrees at 1 Hz
/icons animate --animation sway:1:20

# Scale-pop twice per second on the "available" state icon only
/icons animate --animation ping:2:0.3 --state available

# Remove the rotate animation from this NPC
/icons animate --animation none:rotate

# Remove all animations
/icons animate --animation none

When a state is specified the animation is stored in NpcStateAnimations and overrides both the NPC-level animation and the global DefaultQuestStateAnimations for that state.

/icons list

/icons list
Lists every NPC that has an icon configured — either via a QuestLines quest assignment, a QuestLines random-group assignment, or an explicit /icons icon override. Prints the icon override, Y-offset, scale, and active animations for each NPC. 
/icons list

Output includes a header line showing the global default item ID and base Y-offset, then one line per NPC annotated with any non-default values. Quest-assigned NPCs show [quest=<questId>]; random-group NPCs show [group=<groupId>]. Per-NPC icon, offset, scale, and animation overrides are appended when set.

/icons reload

/icons reload
Reloads mods/Icons/icons.json and the QuestLines mods/QuestLines/npcs.json mirror, despawns all currently active icon entities, and re-queues item updates for every configured NPC. Use this after manually editing icons.json or after NPC quest assignments change in QuestLines. 
/icons reload

icons.json

Located at mods/Icons/icons.json. Created automatically on first save. All keys are optional.

{
  // Global fallback item when no per-NPC override is set
  "DefaultIconItemId": "Recipe_Page",

  // Per-NPC icon overrides  (npcId → itemId | "none")
  "NpcQuestIcons": {
    "Blacksmith": "Icons_Exclamation",
    "TavernKeeper": "none"
  },

  // Per-NPC per-state item overrides  (npcId → stateName → itemId)
  "NpcQuestIconStates": {
    "Blacksmith": {
      "available":   "Icons_Exclamation",
      "inprogress":  "Icons_Dots",
      "completed":   "Icons_Checkmark",
      "unknown":     "Icons_QuestionMark"
    }
  },

  // Global default item per quest state (overrides built-in defaults)
  "DefaultQuestStateIcons": {
    "available":  "Icons_Exclamation",
    "inprogress": "Icons_Dots",
    "completed":  "Icons_Checkmark",
    "unknown":    "Icons_QuestionMark"
  },

  // Per-NPC Y-offset adjustments (blocks, added to base height)
  "NpcQuestIconOffsets": {
    "Blacksmith": 0.5
  },

  // Per-NPC scale overrides (1.0 = default)
  "NpcQuestIconScales": {
    "Blacksmith": 1.5
  },

  // Per-NPC Y-rotation in degrees
  "NpcQuestIconRotations": {
    "Blacksmith": 45.0
  },

  // Per-NPC animations  (npcId → animType → {speed, amplitude})
  "NpcAnimations": {
    "Blacksmith": {
      "bob":    { "speed": 1.0, "amplitude": 0.2 },
      "rotate": { "speed": 45.0, "amplitude": 0.0 }
    }
  },

  // Per-NPC per-state animation overrides
  // When set, completely replaces NPC-level animations for that state's icon
  "NpcStateAnimations": {
    "Blacksmith": {
      "available": {
        "ping": { "speed": 0.5, "amplitude": 0.4 },
        "bob":  { "speed": 0.5, "amplitude": 0.12 }
      }
    }
  },

  // Global default animations per quest state
  // Overrides built-in defaults; overridden in turn by NpcStateAnimations
  "DefaultQuestStateAnimations": {
    "available": {
      "ping": { "speed": 0.5, "amplitude": 0.4 },
      "bob":  { "speed": 0.5, "amplitude": 0.12 }
    },
    "inprogress": {
      "rotate": { "speed": 4.0, "amplitude": 0.0 }
    }
  }
}

Quest states

When integrated with QuestLines, four icon entities are maintained per NPC — one for each quest state. Only the entity matching the player's current state is shown to them.

State nameMeaningDefault item
available The player has not yet started the NPC's quest Icons_Exclamation
inprogress The player has accepted the quest and it is in progress Icons_Dots
completed The player has completed every quest this NPC offers Icons_Checkmark
unknown Quest state is not yet known for this player/NPC pair Icons_QuestionMark

Default animations

Built-in defaults are applied when no per-NPC or DefaultQuestStateAnimations entry overrides them. They can be replaced entirely via DefaultQuestStateAnimations in icons.json.

StateBuilt-in animation
available ping (0.5 Hz, amp 0.4) + bob (0.5 Hz, amp 0.12)
inprogress rotate (4.0 deg/s)
completed rotate (3.0 deg/s)
unknown orbit (0.4 Hz, radius 0.5)
Priority order (highest to lowest)
  1. Per-NPC per-state animation (NpcStateAnimations in icons.json)
  2. Global default per-state animation (DefaultQuestStateAnimations in icons.json)
  3. Built-in plugin defaults (listed above)

QuestStatusProvider API

External plugins (e.g. QuestLines) can drive per-player icon visibility by registering a QuestStatusProvider with the plugin instance. 

// Implement the interface
public class MyQuestProvider implements QuestStatusProvider {

    @Override
    @Nullable
    public QuestState getQuestState(UUID playerUuid, String npcTypeId) {
        // Return null to leave all states visible for this player/NPC pair
        // (useful when your system doesn't track this NPC)
        if (!tracksNpc(npcTypeId)) return null;

        return switch (lookupState(playerUuid, npcTypeId)) {
            case NOT_STARTED -> QuestState.AVAILABLE;
            case IN_PROGRESS -> QuestState.IN_PROGRESS;
            case DONE        -> QuestState.COMPLETED;
            default          -> QuestState.UNKNOWN;
        };
    }
}

// Register it with the plugin
NpcQuestIconsPlugin icons = NpcQuestIconsPlugin.getInstance();
if (icons != null) {
    icons.setQuestStatusProvider(new MyQuestProvider());
}
Null return behaviour Returning null from getQuestState means "I have no data for this pair — leave all icon entities visible." It does not hide the icon entirely. To hide an icon for a specific NPC entirely, set its icon to none via /icons icon none.
