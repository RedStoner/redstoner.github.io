Denizens Plugin

Licensing

Denizens is fully usable for free. A Pro license unlocks a couple of advanced features. Here’s the tier breakdown and how to activate a license.

Tiers

There are two tiers. Free is the default with no license installed (or when a license is unverifiable, not bound to this product, or expired past its grace window). Pro unlocks the paid features.

FeatureTierWhat it does
Core NPC managementFreeCreate, customize, drive, and interact with Denizens — everything on the other pages.
Per-player overridesProShow a different appearance / behavior / interaction to specific players based on requirements.
SchedulesProTime-of-day activity schedules.

Per-Player Overrides

A Pro Denizen can carry a PerPlayerOverrides list. Each override has a Priority, a set of Requirements, and an Apply block that partially overlays the Denizen’s Appearance / Behavior / Interaction. For a viewing player, the highest-priority override whose requirements pass is layered over the base — so one NPC can look or behave differently per player (different skin, different quests, hostile to some, friendly to others). On the free tier these entries round-trip on disk but are not applied.

License Commands

All license commands live under /denizen license and require qldenizen.admin.

CommandWhat it does
/denizen license infoShow the current tier, subject, server-binding status, expiry, days remaining, and per-feature enabled/disabled state.
/denizen license server-idPrint this server’s stable binding id (also logged to console for copying).
/denizen license paste <token>Install a license token. It is verified (signature + product binding) before being written, so a bad token never replaces a good one.
/denizen license refreshRe-read and re-verify license.jwt from disk (e.g. after dropping in a new file).
/denizen license clearDelete the license file and revert to the free tier.
ℹ
Restart to wire features

paste activates the tier immediately for status, but feature wiring is decided at startup — restart the server for newly-unlocked Pro features to come fully online.

Activating a License

  1. Run /denizen license server-id and copy the printed binding id.
  2. On the distributor’s Discord, request a token: /license issue product:denizens server-id:<paste>.
  3. Run /denizen license paste <token> in-game.
  4. Restart the server so the Pro features wire in.

The binding id is derived from the host’s machine identity and the server install directory — there is no hand-editable id file to copy between machines. A server-bound token only runs on the server it was issued for.

Storage & Lifecycle

PathPurpose
mods/QuestLinesDenizens/license.jwtThe installed license token (a single-line signed string).
mods/QuestLinesDenizens/license-config.txtOptional auto-refresh & revocation-check settings (JSON). All off by default.

A license has a grace period after its expiry during which Pro features keep working — if it is re-issued before grace ends, full access simply resumes; otherwise the plugin downgrades to free. If the optional auto-refresh and revocation-check endpoints are configured in license-config.txt, the plugin can renew a near-expiry token and honor a revocation list automatically.
