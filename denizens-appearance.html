Denizens Plugin

Appearance

The in-game editor, the shape of a Denizen entry, and how to set a Denizen’s skin, equipment, scale, and nameplate.

The Editor

/denizen edit [name] (or clicking a Denizen with the editor staff) opens a tabbed editor. Field changes are staged in the form and committed in one step — Apply writes to disk and re-spawns the live entity so your changes take effect immediately. The editor reopens on whichever tab you last used.

TabWhat you set
InfoName, short id, world, anchor position, and role.
AppearanceSkin source, equipment in six slots, and the nameplate.
BehaviorAttitude, leash distance, health, invulnerability, knockback, and respawn rules. See Behavior & AI.
WaypointsThe patrol editor — add, edit, and order waypoints. See Patrols.
AnimationIdle and move animation ids. See Animations.
CombatCombat-related behavior fields (health, invulnerability, knockback).
InteractionClick mode, actions, quests, requirements, cooldown, and reach. See Interaction & Quests.
NameplateNameplateBuilder segment editor. Only shown when NameplateBuilder is installed.

Skin

The Appearance.Skin block decides how a Denizen is textured. The Source picks one of three modes:

SourceExtra fieldResult
None—Use the role’s default skin.
UsernameUsernameFetch and apply a live Minecraft player skin by username. Best on the QLD_PlayerNPC role.
CustomCustomA map of skin part id → texture string, letting you mix individual parts.
 
// Live username skin on a player-model Denizen
"Appearance": {
  "Skin": { "Source": "Username", "Username": "Notch" }
}

Equipment

Appearance.Equipment maps equipment slots to items. Each item is { "ItemId": "...", "Qty": 1 } — Qty defaults to 1 and is omitted when 1. The six slot keys are:

Slot keySlot keySlot key
HeadChestHands
LegsMainHandOffHand
 
"Appearance": {
  "Equipment": {
    "MainHand": { "ItemId": "sword_iron" },
    "Head":     { "ItemId": "helmet_iron" }
  }
}

Scale

The top-level Scale field multiplies the model size (default 1.0). Use it for giant bosses or tiny critters. Set it from the editor’s Info tab or in JSON, then the change applies on the next spawn (/denizen respawn if needed).

Nameplate

Appearance.Nameplate controls the label rendered above the Denizen.

KeyTypeDefaultNotes
Textstring—Nameplate text. Falls back to the Denizen name when unset.

Colorstring—Color for the nameplate text.
