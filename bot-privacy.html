QuestLines Knowledge

Privacy Policy

How the QuestLines Knowledge Discord bot handles your data. In short: it stores as little as possible, never sells anything, and lets you delete what little it keeps at any time.

Last updated: 30 May 2026

Overview

QuestLines Knowledge (“the bot”) is a Discord bot that provides QuestLines documentation, search, and AI-assisted quest tooling. This policy explains what data the bot processes, why, who it is shared with, and how to remove it. By adding the bot to a server or using its commands, you agree to this policy.

What the Bot Stores

The bot keeps only the small amount of data needed to function:

Data When it is stored Why
Your Discord user ID When you use an AI command (/ask, /debug, /newquest) or set a key To enforce per-user usage cooldowns and to associate your saved API key with you.
Your Groq API key Only if you run /setkey and submit one To authenticate your own AI requests so they run on your key with no cooldown. Stored on the bot’s host and used only for your commands. Removable anytime with /forgetkey.
Usage counts & timestamps When you use an AI command A small per-user counter and last-used time, used purely to apply cooldowns.
Server & channel IDs When a server admin configures the bot via /config To remember per-server settings (which channels ! commands work in, auto-translate opt-in and target language).
ℹ
Message content is processed, not logged

To respond to commands the bot reads the text of messages that invoke it (and, in channels where an admin has enabled auto-translation, messages in those channels for language detection). This content is processed in the moment to produce a reply and is not stored as a chat log by the bot.

Third-Party Services

Some features send data to external services to do their job. Those services process it under their own privacy policies:

Service What is sent For
Groq (AI) The text of your question and any quest JSON you attach to /ask, /debug, or /newquest Generating AI answers and quest content. Subject to Groq’s privacy policy. If you supplied your own key with /setkey, the request is billed to your Groq account.
Translation service (LibreTranslate) Message text in channels where an admin enabled auto-translation Detecting the language and producing a translation. Typically self-hosted by the bot operator.
CurseForge Nothing about you — the bot only polls CurseForge for plugin release info Posting release announcements (operator feature). No user data is sent.
Discord Everything transits Discord, the platform the bot runs on Delivering messages and commands. Subject to Discord’s privacy policy.

How Long Data Is Kept

  • Your API key — until you run /forgetkey or the operator removes it.
  • Usage counters — retained to enforce cooldowns; they hold only a count and a timestamp, no message content.
  • Server settings — kept until an admin changes them or the bot is removed from the server.
  • Message content — not retained; used only to produce the immediate response.

Your Choices & Removing Data

  • Remove your API key: run /forgetkey at any time.
  • Avoid AI features: simply don’t use /ask, /debug, or /newquest — the reference and search commands need no stored data.
  • Server data: a Manage-Server admin can clear settings with /config; removing the bot from a server discards its configuration.
  • Other requests: contact the operator (see below) to request deletion of any data associated with your Discord user ID.

What the Bot Does Not Do

  • It does not sell, rent, or trade your data.
  • It does not store chat logs or message history.
  • It does not track you across servers for advertising.
  • It does not request the Server Members or Presence privileged intents.

Age Requirement

The bot is used through Discord and is intended for users who meet Discord’s minimum age requirement (at least 13, or older where local law requires). It is not directed at children below that age.

Changes to This Policy

This policy may be updated as the bot changes. Material changes will be reflected here with a new “Last updated” date. Continued use of the bot after a change constitutes acceptance of the updated policy.

Contact

Questions about this policy, or requests to delete your data, can be directed to the bot operator via the QuestLines community (evilcraft.net) or the QuestLines Discord server.
