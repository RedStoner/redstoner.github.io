Arcade Plugin

Cabinets & Tables

Every Arcade block players can right-click to enter the lobby. The engine routes a F/Use on any block whose Interactions.Use is Arcade_Open through a single listener that looks up the block ID in two maps — one that opens a specific game, and one that opens a category.

ℹ
Lookup order

The listener checks game first (GAME_ID_BY_BLOCK) and falls back to category (CATEGORY_BY_BLOCK). If a game-deep-link block matches but the corresponding pack is not installed, the listener falls through to the category map. Blocks not in either map (notably the Super Secret machine) silently do nothing.

Super Secret Pack

Ships one block — Arcade_Machine_SuperSecret — that is not currently wired to either lookup map. Right-clicking it is a no-op. The pack’s four games are reachable via the STRATEGY, BOARD, CARD, and MULTIPLAYER categories they overlap with.

How the Right-Click Routes

Every Arcade block JSON declares the same use interaction: 

"Interactions": {
  "Use": "Arcade_Open"
}

The engine’s ArcadeMachineUseListener is registered as an entity-store system on plugin setup and intercepts every UseBlockEvent.Pre from a Player entity. When the use string matches, the listener:

  1. Cancels the underlying event so nothing else handles it.
  2. Seeds the player’s wallet from startingTokens if they have no profile yet, and records their current display name.
  3. If the player is in a live (non-terminal) match, re-opens that match’s UI — whatever block they clicked.
  4. Otherwise looks up the block ID in GAME_ID_BY_BLOCK; if matched, opens the lobby at that game’s detail page.
  5. Otherwise looks up the block ID in CATEGORY_BY_BLOCK; if matched, opens the lobby at that category.
  6. Otherwise does nothing.

Where the Blocks Are Defined

The shipped cabinets are item JSONs (under each pack’s resources/Server/Item/Items/) paired with .blockymodel files (under resources/Common/Blocks/QuestLinesArcade/). Block IDs are hardcoded in the listener’s two maps — a custom block with the same Arcade_Open use string will not open the lobby unless its ID is added to one of those maps. The use string by itself is not enough; the listener only acts on block IDs it knows about.
