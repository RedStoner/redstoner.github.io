Core feature

Login Streaks

A per-player consecutive-day login counter with configurable rewards — the classic "log in tomorrow" retention hook. Players who return every day build a streak; missing a day (beyond the grace allowance) resets it. Configured in QuestLines/loginstreak.json; engine is net.evilcraft.questlines.managers.LoginStreakManager.

How It Works

On a player's first connect each day, the engine advances their streak and fires the configured rewards. It is hooked off the same PlayerReadyEvent path as the playerConnect event, and runs before playerConnect actions so {streak} is already up to date for them.

A "day" is the UTC epoch-day, shiftable with ResetOffsetHours so roll-over lines up with your server's local midnight (e.g. -5 for US Eastern). Connecting again later the same day does nothing. Streak state is stored on PlayerData (loginStreak, longestLoginStreak, lastStreakDay) and persists across restarts.

Streak Progression

GraceDays is the number of missed days that are forgiven. 0 = strict (must log in every consecutive day). 1 lets a player skip a single day and still continue. Grace does not credit the skipped days — the streak still advances by exactly +1 per login day.

Gap since last counted dayResult
Same dayNo change (already counted)
1 day (yesterday)Streak +1 (consecutive)
Missed days <= GraceDaysStreak +1 — gap forgiven (counts as grace used)
Missed days > GraceDaysStreak resets to 1 (counts as broken)
Never logged inStreak starts at 1

Config File

QuestLines/loginstreak.json is seeded with a working example on first run. All reward values are ordinary QuestLines action strings — any ActionManager type works (chat:, giveitem:, title:, elxp:, rpgxp:, command:, ...). Rewards fire after the counter is bumped, so {streak} / {streak:longest} resolve to today's value inside them. 

// QuestLines/loginstreak.json
{
  "Enabled": true,
  "ResetOffsetHours": 0,
  "GraceDays": 1,
  "DailyActions": [
    "chat:Welcome back! You're on a {streak}-day login streak."
  ],
  "BrokenActions": [
    "chat:Your login streak reset. Log in daily to build it back up!"
  ],
  "GraceActions": [
    "chat:You missed a day, but your {streak}-day streak survived."
  ],
  "Milestones": {
    "3":  ["chat:3-day streak! Keep it going."],
    "7":  ["chat:A full week! Here's a bonus.", "giveitem:SomeItemId:1"],
    "14": ["chat:14-day streak - you're dedicated!"],
    "30": ["chat:30-day streak! Legendary commitment.", "title:Devoted"]
  },
  "RepeatEvery": 0,
  "RepeatActions": []
}
KeyTypeMeaning
EnabledboolMaster switch. When false, no streak tracking or rewards occur.
ResetOffsetHoursintHours to shift the UTC day boundary (negative = west of UTC).
GraceDaysintMissed days forgiven before the streak resets. 0 = strict; 1 = one skipped day allowed.
DailyActionsstring[]Fired every new counted day — the base daily-login reward.
BrokenActionsstring[]Fired when a player returns after a gap too long to forgive (streak reset to 1).
GraceActionsstring[]Fired when a missed-day gap was forgiven by GraceDays (streak continued).
MilestonesmapMap of exact streak length → reward actions (fires once, on the day the streak hits that number).
RepeatEveryintFire RepeatActions every N streak-days (0 = disabled). Stacks with DailyActions / Milestones.
RepeatActionsstring[]The repeating reward list.

Firing order on a newly counted day: DailyActions → BrokenActions (if broken) or GraceActions (if a gap was forgiven) → Milestones[streak] (if any) → RepeatActions (if RepeatEvery divides the streak). BrokenActions and GraceActions are mutually exclusive.

Quest Integration

The streak counter is exposed to the quest engine as requirements, actions, and text variables, so you can gate content or display progress with the existing tooling.

SurfaceFormatNotes
Requirementstreak:daysCurrent streak ≥ N
Requirementlongeststreak:daysAll-time best ≥ N
Actionsetstreak:NSet current streak (raises best if higher)
ActionresetstreakClear current streak to zero
Variable{streak}Current streak
Variable{streak:longest}All-time best
Variable{streak:next}Next configured milestone day (empty if none)

Gate a daily-quest board on streak:7, show You're on day {streak}! in dialogue, or hand a prestige title: at a 30-day milestone — all reuse the existing quest tooling.
