Core feature

Daily Quests

A pool of quests, of which a fresh subset is offered each day. Players open /daily, pick up today's quests, complete them for rewards, and a different set rotates in tomorrow — the recurring "something new to do today" hook that pairs with login streaks. Configured in QuestLines/dailyquests.json; engine is net.evilcraft.questlines.managers.DailyQuestManager.

How It Works

Today's set is a deterministic selection from the configured pool, seeded by the day number — so it is the same for every player, stable across restarts, and changes each day. There is no per-server randomness to persist.

Players view and accept today's quests with /daily (aliases dailies, dq), which opens a board-style UI (the same QuestBoardUI that powers placed Quest Boards). Clicking a quest opens its normal dialogue / accept flow. Accepted dailies show on the quest HUD like any other tracked quest.

A "day" is the UTC epoch-day shifted by ResetOffsetHours — its own boundary, independent of the login-streak offset.

Daily Reset

Once per player per day — on connect (EventActionsListener.onPlayerReady) and when /daily is opened — the player's completed / started / tracked state for every pool quest is cleared, so the rotation is re-doable. Within a day, quests the player has already completed are hidden from the board so they can't be repeated until the next rotation.

Because reset wipes completion for pool quests, a pool quest ID should be dedicated to the daily system — don't reuse a one-time story quest's ID in the pool. Mark pool quests "Repeatable": true so the journal lists them in the repeatable tab rather than as permanently completed.

Config File

QuestLines/dailyquests.json is seeded with an empty pool on first run — add your quest IDs. 

// QuestLines/dailyquests.json
{
  "Enabled": true,
  "Count": 3,
  "ResetOffsetHours": 0,
  "Title": "Daily Quests",
  "Pool": [
    "daily_gather_wood",
    "daily_slay_goblins",
    "daily_catch_fish",
    "daily_mine_ore",
    "daily_deliver_parcel"
  ]
}
KeyTypeMeaning
EnabledboolMaster switch. When false, /daily reports the feature is off and no reset runs.
CountintHow many quests from the pool are offered each day.
ResetOffsetHoursintHours to shift the UTC day boundary (negative = west of UTC).
TitlestringShown as the board subtitle (e.g. "Daily Quests").
Poolstring[]Quest IDs eligible for rotation. If Count >= pool size, all of them show every day.

Authoring Daily Quests

Daily quests are ordinary quests — give each one a quest JSON with pages, objectives, and completion rewards (any action: giveitem:, elxp:, title:, chat:, ...). Recommended:

  • Set "Repeatable": true.
  • Keep them short / completable in one session.
  • Reward currency or a streak-style token so dailies feed your economy.

Then list their IDs in Pool. That's it — the rotation, reset, and board are automatic.

Tips

  • Pair with login streaks: gate a bonus daily behind streak:7, or have a milestone hand out a currency players spend elsewhere.
  • The same QuestBoardUI powers placed Quest Board blocks and NPC-as-board questgivers, so a daily-style board is a natural companion to the /daily command.
