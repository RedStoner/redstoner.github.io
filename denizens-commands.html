Denizens Plugin

Commands

Everything is managed through the single /denizen command tree. Run it bare to open the manager UI, or use a subcommand for scriptable control.

Permission

Every /denizen subcommand — and opening the manager UI — requires the qldenizen.admin permission (default false). The console is always allowed and falls back to the help listing where a UI would otherwise open.

ℹ
Selecting a Denizen

Subcommands that take a <name> accept a Denizen by display name, #shortId, full UUID, or an unambiguous UUID prefix. Where the name is shown as [name] (optional), omitting it falls back to your current wand selection.

Subcommands

CommandDescription
/denizenOpen the manager UI (Browse + Create tabs).
/denizen helpList every subcommand with a short description.
/denizen create <roleName> [name]Create and spawn a Denizen at your position and rotation. roleName must be a valid NPC role (see roles). name is an optional admin label — it defaults to the role name. Player-model roles auto-default their skin to the given name. A #shortId is allocated automatically.
/denizen list [filter]List all Denizens. The optional filter is world:<name>, tag:<tag>, or a case-insensitive name substring. Each row shows short id, name, UUID, role, world, position, and spawned/offline status.
/denizen inspect [name]Print a Denizen’s persisted fields in chat (name, ids, role, world, anchor, scale, status, tags, equipment, nameplate, attitude, interaction mode).
/denizen tp <name>Teleport you to the Denizen’s anchor (position + rotation). Crosses worlds.
/denizen movehere [name]Move the Denizen’s anchor to your current position, rotation, and world, then respawn it there.
/denizen clone [name]Duplicate a Denizen under a fresh UUID and short id, copying all fields.
/denizen remove <name>Despawn and permanently delete the Denizen, removing its JSON file. Clears the wand selection if it pointed at it.
/denizen respawn [name]Force a despawn + respawn to refresh the live entity — use after editing the JSON by hand.
/denizen patrol <freeze|resume> [name]Hold a patrolling Denizen in place (freeze) or release it (resume). The held state persists across respawn and restart. No-op if no patrol is configured. (Also accepts stop/hold/pause and start/go/unfreeze.)
/denizen edit [name]Open the tabbed in-game editor for a Denizen. See The Editor.
/denizen wandToggle wand-mode — see Wand Selection below.
/denizen roles [filter]List spawnable NPC role names — see Discovering Roles below.
/denizen import-hc [dry]Migrate HyCitizens NPCs into Denizens — see HyCitizens Import.
/denizen license <sub>View and manage the license — see License Commands.

Wand Selection

/denizen wand toggles wand-mode for you. While armed, the next Denizen you click is stored as your selection (the mode times out after about 60 seconds). Once selected, subcommands written without a name argument — tp, inspect, movehere, clone, remove, respawn, patrol, edit — act on that selection.

The wand click overrides the Denizen’s normal interaction mode, so you can select even a quest-giver NPC without triggering its dialogue.

The Editor Staff

The asset pack ships an admin item, QuestLinesDenizens_Staff. An admin holding the staff who clicks a Denizen opens its editor directly — a fast alternative to typing /denizen edit <name>. Like the wand, the staff bypasses the Denizen’s normal click interaction.

Discovering Roles

/denizen create needs a valid NPC role id. Run /denizen roles to list every spawnable role registered with the server, optionally filtered by a case-insensitive substring. Up to 80 matches are shown in chat; the complete list is always written to the server console. 

// Find every goblin role, then spawn one
/denizen roles goblin
/denizen create Goblin_Boss Camp Warlord
⚠
Use real role ids

Role ids must match the catalogue exactly. /denizen roles is the authoritative source — don’t guess names.
