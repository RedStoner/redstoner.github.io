Claims Plugin

Commands

Every /claim subcommand — player-facing tools and the admin region/wand workflow.

Root command: /claim.

Player Commands

Command Permission Description
/claim help none List all /claim subcommands in chat.
/claim info none Show details about the region or claim the player is standing in.
/claim map
aliases: /claim c, /claim claims 		questlinesclaims.claim.use Open the chunk claim map centred on the player. Standing in own claim opens it in edit mode; standing in wilderness opens it in new-claim mode; standing in another player’s claim is refused.
/claim members none Open the members UI for the claim the player is standing in. Only the owner may open it.
/claim manage none (context-dependent) Open the appropriate member manager at the player’s position: their own claim, a rent region they hold, or a buy region they own. Admins can manage any region, any claim, or the wilderness member list from this command.
/claim rentbuy questlinesclaims.claim.use Open the Rent/Buy Browser to view and transact on available plots.
/claim buychunk [count]
alias: /claim buychunks 		questlinesclaims.claim.use Spend Claim Shards from your inventory to raise your chunk limit. Each chunk costs chunk_cost_shards (default 32); count defaults to 1. All-or-nothing — refused if you can’t cover the full cost.
/claim show none Outline every claim and admin region within a 6-chunk radius of the player for 30 seconds. Useful for spotting boundaries on the ground without opening the map.

Admin Commands

All commands below require questlinesclaims.admin.

Command Description
/claim wand Give yourself the Claim Staff and reset your wand selection.
/claim pos1 Set Pos1 to your current block position. Wand-less alternative for clients where a mod intercepts the Claim Staff clicks.
/claim pos2 Set Pos2 to your current block position. Wand-less alternative for clients where a mod intercepts the Claim Staff clicks.
/claim select <x1> <y1> <z1> <x2> <y2> <z2> Set both Pos1 and Pos2 from explicit block coordinates in a single command.
/claim deselect Clear your selection (rectangle corners and polygon vertices) and stop the selection box render.
/claim polymode Toggle the wand session between rectangle mode and polygon mode. In polygon mode wand left-click adds a vertex and right-click removes the last one. Need 3+ vertices to save. Also registered as /region polymode.
/claim admin Open the admin region list UI to create, edit, delete, and save prefabs.
/claim create Shortcut for the admin region edit form, pre-filled with the player’s current wand selection if set.
/claim addchunks <username> <amount> Adjust a player’s bonus chunks on top of their permission-based limit. Pass a negative amount to remove bonus chunks.
/claim setowner <username> Transfer ownership of the claim at the player’s current chunk to another player. Chunk count is checked against the new owner’s limit (admins exempt). Pass server to transfer to the server pseudo-player.
/claim settenant <username|clear> Set or clear the tenant of the rent region at the player’s current position. Does not charge the new tenant and starts a fresh lease (leaseStart = now, leaseEnd = now + durationSeconds); members and warning thresholds are cleared. Pass clear to vacate the region instead. Also available as an Assign/Clear control on the admin region edit UI when the region is a rent region.
/claim giveshards [amount] Give yourself a stack of Claim Shards (amount defaults to 16). For testing and hand-distribution — the intended in-world source is quest rewards (giveitem:QuestLinesClaims_ClaimShard:N).
/claim reload Reload plugin configs from disk.
/claim import <source> [--path=<path>] Import claims from another plugin's data store. source is either simpleclaims (SQLite DB, defaults to <universe>/SimpleClaims/SimpleClaims.db) or wiflowsclaims (JSON data directory, defaults to <universe>/WiFlowsClaims/). Appends — existing QL claims are left untouched.
