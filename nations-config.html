Nations Plugin

Config & Admin

The full questlinesnations.conf key reference, the permission node, the conquest flow, and the on-disk file layout.

File Layout

All Nations data lives under mods/QuestLinesNations/. 

mods/QuestLinesNations/
  questlinesnations.conf     plugin settings (this page)
  nations.db                 SQLite database

Missing keys in questlinesnations.conf are written back with defaults on first load — you can ship a stub file and let the plugin fill it in.

Permissions

NodeDefaultDescription
questlinesnations.adminopRequired for /citiesadmin and /nationsadmin subtrees. Also bypasses both ownership resolvers at step zero.

Player-facing commands (/city, /nation) are not permission-gated — they’re open to everyone, with access controlled internally by per-rank bitmasks.

Conquest

Conquest is the admin-staged finishing move that consumes a losing entity into a winning one. It exists at both tiers with identical syntax. Because it’s irreversible, both commands require a confirm-token round-trip: 

/citiesadmin conquer <loser> <winner> [claims|absorb]
/nationsadmin conquer <loser> <winner> [claims|absorb]

The first invocation prints a token and the exact re-run command. Within conquest_confirm_token_ttl_seconds (default 60) you re-invoke with the token appended to execute.

What happens in both modes

Regardless of mode, the loser is fully dissolved:

  • Every chunk the loser owned is unclaimed and re-claimed under the winner’s ownership.
  • The loser’s entire treasury is added to the winner’s treasury, audited as a conquest:<loserName> CREDIT row on the winner.
  • All of the loser’s alliances flip to BROKEN; all of its active wars flip to ENDED_BY_DISBAND.
  • The loser’s pending invites and share grants are wiped.
  • The loser row itself is deleted.

Mode difference: members

ModeWhat happens to the loser’s members
claims (default) Ejected to no-city / no-nation state. They’re free to join or found a new entity.
absorb Migrated into the winner at the winner’s Default rank. The loser’s mayor loses mayor status — everyone comes in equal.

Co-nation conquest is allowed: a member-city absorbing another member-city may push their shared nation into grace if it drops below quorum.

Manifest & Versioning

Nations ships as questlines-nations-{version}.jar placed in mods/. The plugin manifest declares: 

{
  "Group": "net.evilcraft",
  "Name": "QuestLinesNations",
  "Main": "net.evilcraft.questlinesnations.QuestLinesNationsPlugin",
  "LoadOrder": "POSTWORLD",
  "Dependencies": {
    "net.evilcraft:QuestLinesClaims": "*"
  },
  "OptionalDependencies": {
    "TheNewEconomy:VaultUnlocked": "*"
  }
}

Claims is hard-required at the manifest level so Hytale loads it first; VaultUnlocked is optional and surfaces through the VaultUnlockedEconomyService bridge inside the plugin (falling back to a no-op service if absent).
