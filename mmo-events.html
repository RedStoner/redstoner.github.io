Events & Discoveries

World-driven dynamic events and bosses that fire on player density, and proximity-detected points of interest players unlock as they explore.

Dynamic Events

Dynamic events are time-bounded encounters that fire inside specific world regions when player density is high enough. They are configured in two pieces:

  • Event definitions in mods/QuestLinesMMO/events/definitions/ — the encounter itself: display name, min/max duration, success reward.
  • Region triggers in mods/QuestLinesMMO/events/regions/ — the world box and the list of event IDs eligible to spawn there, plus a per-region minimum player count.

Every config.events.dynamicEventCheckIntervalMinutes minutes (default 10) the manager picks an eligible region (one with at least its minPlayers inside it and not on cooldown), then rolls one of the region’s eligible events with a random duration in [minDurationSeconds, maxDurationSeconds]. Success rewards are distributed to every player in the region at the time of completion.

Spawn Modifiers

Each entry in a "defeat" event’s spawns list can carry an optional "modifiers" block that scales the mob’s combat numbers at spawn time. Both multipliers default to 1.0 (no change); omit the block entirely for vanilla stats.

  • healthMultiplier — multiplies the mob’s Health stat ceiling. The mob is then maximised so it starts at the new cap.
  • damageMultiplier — every outgoing damage event sourced from this mob has its amount multiplied by this value before the engine applies it.

Example from goblin_raid.json:

"spawns": [
  { "entityType": "Goblin",        "count": 6, "spreadRadius": 12.0 },
  { "entityType": "Goblin_Lobber", "count": 2, "spreadRadius": 16.0,
    "modifiers": { "damageMultiplier": 1.25 } },
  { "entityType": "Goblin_Duke",   "count": 1, "pos": { "x": 0, "y": 120, "z": 0 },
    "modifiers": { "healthMultiplier": 2.5, "damageMultiplier": 1.5 } }
]

Event Bosses

Event bosses are large encounters that can be spawned during a dynamic event or by an admin command. Each boss is a JSON file under mods/QuestLinesMMO/events/bosses/ that names a Hytale entityType, a max-health override, a despawn timer, and a reward table. Damage dealt is tracked by the ParticipationTracker; on boss death, every contributor whose damage cleared config.events.eventBossMinDamageThreshold gets a share of the reward.

World Bosses

World bosses are scheduled spawns rather than dynamic ones. Definitions in mods/QuestLinesMMO/bosses/ include a cron-style schedule, a fixed spawn coordinate, and an optional override for the announcement windows (default config.worldBosses.announcementTimes = ["15m","5m","1m"]). At each scheduled time the scheduler announces a countdown, then spawns the boss at the configured location. An admin can force a spawn outside the schedule with /qlmmo admin forceboss <worldBossId>.

Discoveries (POIs)

A POI is a sphere centred on a coordinate in a specific world. While the PoiManager ticks (every config.poi.proximityCheckIntervalSeconds seconds, default 2) it scans every online player against every POI; the first time a player enters the radius, the POI is recorded as discovered for them, a notification fires, and any rewards on the POI are granted.

Players open /discoveries (alias /poi) to see every POI they’ve discovered with its world, coordinates, and description. POIs marked "hidden": true stay invisible until discovered; non-hidden ones can be listed with their location even before discovery so that admins can flag landmarks on the world map.

Admin authoring is done with /qlmmo poi here <id> while standing at the desired centre — this writes the JSON file directly. Other authoring commands let admins teleport to a POI, list every registered POI, and grant or revoke discoveries on a player’s behalf.
