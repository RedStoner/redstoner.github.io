QuestLines Knowledge

The QuestLines Discord Bot

QuestLines Knowledge is a Discord bot that puts the entire QuestLines wiki at your fingertips. Look up any action, requirement, or text variable, search the docs, get AI-grounded answers to “how do I…” questions, and even generate or debug quest JSON — all without leaving Discord.

What It Does

Every command works as a Discord slash command (type / and pick it from the menu) and most also work with the legacy ! message prefix. Slash commands reply privately to you (only you see the answer), so you can use them anywhere without cluttering chat.

  • Reference lookups — actions, requirements, text variables, formatting tags, NPC setup, quest patterns, and full doc search.
  • Ask anything — /ask answers plain-English questions using the real documentation.
  • Quest tooling — /newquest writes a quest from a description, /debug explains why a quest isn’t working, and /review validates a file for errors.
ℹ
Slash vs. ! prefix

Slash commands (/ask) are recommended — they autocomplete and answer privately. The ! prefix (!ask) does the same thing but posts in-channel. A server admin may limit where ! commands work; if ! seems ignored, try the slash version or ask an admin (see the Admin & Setup page).

Commands

Everything available to regular members. Arguments in <angle brackets> are required; [square brackets] are optional.

Command What it does
/ask <question> Ask anything about QuestLines. An AI answers using the docs (e.g. “how do I build a kill quest”).
/search <query> Full-text search across the entire wiki.
/action [name] Look up an action string (questStarted, addTag, track…). Use all to list every action.
/req [name] Look up a requirement string (kill, hasTag, cooldown…). Use all to list every requirement.
/npc [topic] NPC setup, wand mode, random quest pools, and linking quests to NPCs.
/variable All {text variables} usable in dialogue and response text.
/formatting Inline text formatting tags ({b}, {i}, {#RRGGBB}…).
/portrait The NPC portrait image system.
/anim QuestLines Icons animation types (bob, rotate, orbit, ping…).
/pattern [name] A full worked quest example with JSON (kill, daily, timed, branching, multi-npc, item-turnin), or all.
/plugin [name] A plugin overview (core, icons, dialog…).
/newquest <description> AI quest generator. Describe a quest and receive a ready-to-use .json file.
/debug <file> [question] AI quest debugger. Attach your quest .json and ask why something isn’t working.
/review <file> Validate an attached quest .json for errors and logic issues (no AI — fast and free).
/setkey · /forgetkey Use your own free Groq API key for the AI commands (no cooldown). See Use Your Own API Key.
/help Show all available commands.
ℹ
Some commands are server-specific

A few extras (such as the /qlname supporter banner generator) only exist on the official QuestLines community server and won’t appear when the bot is added to other servers.

Asking Questions

/ask is the fastest way to get an answer. It pulls the most relevant wiki entries and has an AI write a focused, grounded reply — with a “Related docs” footer linking the sources. It only answers from the real documentation, so it won’t invent syntax. 

// Walk through a whole workflow
/ask how do I build a daily repeatable quest

// Clarify one concept
/ask what does AutoTrigger do

// Compare two things
/ask difference between hasTag and global:hastag
💡
Need exact syntax instead?

For a specific string, /action <name> or /req <name> gives the precise format instantly with no AI. /search casts the widest net.

Generating & Debugging Quests

Three commands take you from idea to working quest:

  • /newquest <description> — describe the quest in plain English and the bot returns a complete, downloadable quest .json you can drop into QuestLines/quests/ and /ql reload.
  • /debug <file> [question] — attach a quest file and ask what’s wrong. The bot runs the same validator the plugin uses, then has the AI explain the result and answer your question.
  • /review <file> — a pure validation pass (no AI). Lists structural errors and logic warnings. Great as a final check before shipping.
ℹ
Always sanity-check generated quests

AI output is a strong starting point, not a guarantee. Run /review on a generated file and test it in-game before relying on it.

Use Your Own API Key

The AI commands (/ask, /debug, /newquest) share a per-user cooldown so the bot stays affordable to run. You can lift that cooldown entirely by supplying your own free Groq API key — the AI then runs on your key, billed to you, with no waiting.

Step Do this
1 Get a free key at console.groq.com/keys (it starts with gsk_).
2 Run /setkey. A private popup appears — paste your key there. It never shows in any channel.
3 The bot checks the key works, saves it, and confirms. AI commands now run on your key with no cooldown.
— Run /forgetkey at any time to remove your stored key.
💡
Always enter your key through the popup

Never paste an API key directly into a chat message — anyone (and other bots) could read it. The /setkey popup keeps it private. Your key is stored on the bot host only for your own commands and can be removed with /forgetkey.

ℹ
On servers other than the official one

When the bot is added to another community’s server, the AI commands require your own key — run /setkey first. The free reference and search commands work everywhere with no setup.
